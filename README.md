# MikroCentauri

RouterOS-native selective routing application, currently **research / dataplane spike**.
RouterOS remains the main router. A sing-box gateway is intended to handle selected
resources and devices. No production deployment or working RouterOS integration
is claimed yet. Full UI work is gated on a proven dataplane.

Target: RouterOS >= 7.22; linux/arm64 and linux/amd64.
